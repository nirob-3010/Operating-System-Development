# Desktop composition

The functional composition is:

- ROX-Filer pinboard → desktop icons + wallpaper
- JWM → window management and root context menu
- tint2 → translucent light top panel, task list, clock, status line
- wbar → centered bottom dock
- Xdialog → launcher/settings/power dialogs
- aterm → lightweight terminal

This intentionally avoids a heavyweight desktop environment.
